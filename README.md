# TaskFlow — Your calm workspace

A React + Vite task management dashboard using a Forest, Cream, and Coral palette.

## Requirements
- Node.js (LTS)

## Setup
```bash
npm install
npm run dev
```

Open the local URL Vite prints (usually http://localhost:5173).

## Build
```bash
npm run build
```

## Stack
- React
- Vite
- Bootstrap
- Lucide React
- CSS
